# 5th Grade - At a restaurant (Unit 6)

Vanilla HTML/CSS/JS, no build step. Open `index.html` or serve the folder (GitHub Pages works as-is).

Two modes, chosen on the home screen:
- **Speaking practice**: order three items from a random menu, then reveal the total.
- **Time attack**: teams race through orders pair by pair (settings: teams, rounds, players per team, items to order).

Files
- `css/clr.css`: CLR design system (shared)
- `css/restaurant.css`: layout for this app (orange = speaking practice, grape = time attack)
- `js/menu.js`: food names, prices and image file names
- `js/app.js`: screens and game logic
- `js/icons.js`: inlined Phosphor icons
- `js/sound.js` + `sfx/`: sound effects (Cardbox v3 SFX pack)
- `images/`: food images (see `images/README.md`)
