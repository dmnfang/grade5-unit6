# Food images

Drop one image per menu item in this folder. The file name must match the `img` value in `js/menu.js`.
The app tries `.png`, `.webp`, `.jpg` and `.jpeg` automatically. Until a file exists, an emoji placeholder is shown.
Use lowercase file names exactly as below (GitHub Pages is case-sensitive).

| File name (no extension) | Item | Type |
|---|---|---|
| hamburger | hamburger | main |
| hot-dog | hot dog | main |
| pizza | pizza | main |
| sandwich | sandwich | main |
| curry-and-rice | curry and rice | main |
| grilled-fish | grilled fish | main |
| fried-chicken | fried chicken | main |
| sushi | sushi | main |
| steak | steak | main |
| french-fries | French fries | side |
| salad | salad | side |
| soup | soup | side |
| rice-ball | rice ball | side |
| ice-cream | ice cream | dessert |
| cake | cake | dessert |
| parfait | parfait | dessert |
| pudding | pudding | dessert |
| shaved-ice | shaved ice | dessert |
| donut | donut | dessert |
| juice | juice | drink |
| tea | tea | drink |
| green-tea | green tea | drink |
| milk | milk | drink |
| coffee | coffee | drink |
| cola | cola | drink |

To add an item, add a line to `js/menu.js` and put a matching image here.
