# Food images

Drop one image per menu item in this folder. The file name must match the `img` value in `js/menu.js`.
The app tries `.png`, `.webp`, `.jpg` and `.jpeg` automatically. Until a file exists, an emoji placeholder is shown.

| File name (no extension) | Item | Type |
|---|---|---|
| hamburger | hamburger | main |
| pizza | pizza | main |
| spaghetti | spaghetti | main |
| curry-and-rice | curry and rice | main |
| steak | steak | main |
| french-fries | French fries | side |
| salad | salad | side |
| soup | soup | side |
| fried-chicken | fried chicken | side |
| ice-cream | ice cream | dessert |
| cake | cake | dessert |
| pancakes | pancakes | dessert |
| donut | donut | dessert |
| orange-juice | orange juice | drink |
| tea | tea | drink |
| milk | milk | drink |
| cola | cola | drink |

To add an item, add a line to `js/menu.js` and put a matching image here.
